# Future Work

This file is a non-authoritative incubator for questions that are not yet requirements. `URACE.md` remains authoritative, and `README.md` remains the public usage guide. Nothing here grants Authority, changes runtime behavior or commits the project to implementation.

## Candidate investigations

- **Specification compression and landmarks:** determine whether shorter editions can preserve normative precision, and whether placement or ordering causes readers or Executors to assign unintended priority.
- **Vocabulary precision:** assess whether distinctions such as innovation versus evolution, or applies versus adheres, improve decisions enough to justify additional terminology.
- **Principle-to-implementation conformance:** investigate small, inspectable ways to show which generated behavior satisfies each portable requirement without duplicating the specification or coupling it to one runtime.

Promote an item into `URACE.md` only when Evidence shows a portable requirement is missing. Promote explanatory material into `README.md` only when it improves user understanding. Deployment-specific experiments, paths and adapter details remain local.
